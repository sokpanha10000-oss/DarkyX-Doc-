DarkyX documentation
DARKER • CLEANER • ANIMATED

Build Roblox interfaces with a DarkyX feel.

DarkyX is a compact Roblox UI library built around dark surfaces, focused controls, smooth motion, and a clean API. This documentation gives you the full path from your first window to a complete multi-element hub.

Get Started → CreateWindow ⌘
◈
Dark-first UI

Low-noise surfaces with controlled contrast.

✦
Animated feel

Soft motion for menus, controls, and navigation.

⌘
Simple API

Create windows and elements without heavy setup.

01

Get Started

Load the latest DarkyX library first. This is the only required startup line.

Loadstring
local DarkyX = loadstring(game:HttpGet("https://github.com/sokpanha10000-oss/DarkyUI/releases/latest/download/DarkyX.lua"))()
Keep your project modular.Load DarkyX once, then use the returned library object to create your window and controls.
02

Quick Start

Create a window, then add a tab and your first control.

Minimal setup
local DarkyX = loadstring(game:HttpGet("https://github.com/sokpanha10000-oss/DarkyUI/releases/latest/download/DarkyX.lua"))()

local window = DarkyX:CreateWindow({
    Title = "DarkyX Hub",
    subtitle = "DarkyX",
    Image = "house",
    sidebarLayout = false,
    theme = "Default",
})

local tab = window:CreateTab({
    name = "Combat",
    icon = 93364949241311,
})

tab:CreateButton({
    name = "Reset character",
    description = "Reset your current Roblox character.",
    callback = function()
        game.Players.LocalPlayer.Character:BreakJoints()
    end,
})
04

CreateWindow

The root object controls your library window and its base presentation.

Start with the window.Everything else is created from the Window object.
Next: CreateTab →
DarkyX:CreateWindow(config)ROOT
TitleWindow title text.
subtitleSecondary title text shown with the window branding.
ImageWindow image/icon value. Your example uses "house".
sidebarLayoutControls the sidebar-style layout. Your example sets it to false.
themeBase visual theme. Your example uses "Default".
05

Tags

Small status or environment labels attached to the window.

Create
local tag = window:CreateTag({
    text = "us-en",
    color = Color3.fromRGB(255, 175, 15),
})
Update
tag:Set({
    text = "live",
    color = Color3.fromRGB(80, 200, 120),
})

BUTTONtab:CreateButton({...})

Use a button for one-shot actions. The callback runs when the user activates it.

Usage
tab:CreateButton({
    name = "Reset character",
    description = "Reset your current Roblox character.",
    callback = function()
        game.Players.LocalPlayer.Character:BreakJoints()
    end,
})
TOGGLEtab:CreateToggle({...})

A boolean control for enabling or disabling a module. Use a flag for a stable setting name.

Usage
tab:CreateToggle({
    name = "Auto Sprint",
    flag = "AutoSprint",
    value = false,
    callback = function(value)
        print("Auto Sprint:", value)
    end,
})
DROPDOWNtab:CreateDropdown({...})

Present one or multiple choices. multiSelect = true enables multiple active values, and the created dropdown can be refreshed later.

Usage
local Dropdown = tab:CreateDropdown({
    name = "Modules",
    multiSelect = true,
    options = {"Aimbot", "ESP", "Fly", "Noclip"},
    value = {"ESP"},
    callback = function(selected)
        print(selected)
    end,
})

Dropdown:Refresh({"Jump Boost", "Speed Boost"})
SLIDERtab:CreateSlider({...})

Use a numeric slider with a minimum/maximum range, step size, starting value, and optional suffix.

Usage
tab:CreateSlider({
    name = "Field of view",
    range = {70, 120},
    increment = 1,
    value = 90,
    suffix = "°",
    callback = function(value)
        workspace.CurrentCamera.FieldOfView = value
    end,
})
INPUTtab:CreateInput({...})

Collect text from the user. Set numeric = true when the field should accept numbers only.

Usage
tab:CreateInput({
    name = "Max players",
    numeric = true,
    value = "16",
    placeholder = "Enter a number",
    callback = function(text)
        print("Committed:", text)
    end,
})
STATtab:CreateStat({...})

Display a number or tracked value. The returned object exposes :Set() for updates.

Usage
local revenue = tab:CreateStat({
    name = "Revenue",
    prefix = "$",
    value = 12400,
})

revenue:Set(revenue.value + 500)
COLOR PICKERtab:CreateColorPicker({...})

Let the user choose a color. The callback receives the selected color and alpha value.

Usage
tab:CreateColorPicker({
    name = "Highlight",
    color = Color3.fromRGB(96, 205, 255),
    callback = function(color, alpha)
        print(color, alpha)
    end,
})

09

Visual System

The documentation theme intentionally mirrors the DarkyX direction: darker surfaces, soft light, and controlled animation.

Soft glow

Localized highlights replace harsh neon borders, keeping controls readable without flooding the screen.

Micro motion

Navigation and cards use small transitions so movement supports hierarchy rather than distracting from it.

Depth layers

Glass panels, darker inner surfaces, and subtle strokes create a stacked interface instead of a flat page.

12

Notes & Conventions

Small patterns that keep a DarkyX project clean and predictable.

Names

Use readable element names and short descriptions so a crowded hub remains easy to scan.

Flags

Use stable flag strings for settings that you may need to reference consistently.

Callbacks

Keep callbacks focused on one job and move larger systems into your own modules.

Refreshable controls

Keep the returned control object when you need to update it later, such as dropdown options or stats.
